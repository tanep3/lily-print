# Lily Print — LX-D02 用 Windows GUI 印刷アプリ

サーマルミニプリンター「Lily」（BLE 名 LX-D02）を Windows から印刷する単発 GUI アプリ。
ファイルを選ぶ → 384px 実寸プレビュー → 印刷ボタン、という流れ専用。
印刷エンジンは OSS の [lxd02-printer](https://pypi.org/project/lxd02-printer/) をライブラリとして使う。

## ダウンロード

使うだけなら **[Releases](https://github.com/tanep3/lily-print/releases)** から `LilyPrint.exe` を
ダウンロードすればよい（Python 不要）。`v*` タグを切ると GitHub Actions が自動で exe をビルドし、
そのタグの Release に添付する。

## 導入（ソースから動かす場合・Windows）

前提：Python 3.12 以上。

```powershell
pip install lxd02-printer tkinterdnd2
python lily_print.py
```

（tkinterdnd2 はドラッグ＆ドロップ用。無くてもファイル選択からは使える）

## 使い方

1. プリンタの電源を入れ、**スマホの Bluetooth を OFF** にする（BLE 接続は 1 つだけ）。
   USB 給電でデスクに置いたままの運用が前提。
2. 「ファイルを開く」で画像（PNG / JPG 等）を選ぶ。ウィンドウへのドラッグ＆ドロップでも可（複数落としたら先頭の 1 個）。ブラウザ等でコピーした画像は「貼り付け」ボタンか Ctrl+V でも入れられる。
3. プレビューは**実際に刷られるドットそのもの**（横 384 ドット、×2 表示）。縦に長い画像でもウィンドウは伸びず、プレビュー枠内をホイール／スクロールバーでスクロールして見る。
   - ディザ：写真向き（階調を網点で再現）
   - 二値：QR や線画向き（白黒をはっきり分ける）
4. 濃さ（1〜6、プリンタに記憶される）と部数を選び、「印刷」。
5. 「状態を確認」で電池・紙・濃さが見られる。

プリンタの MAC アドレスはコードに含まれていない。初回は「探す」ボタンを押すか、
アドレス欄が空のまま印刷／状態確認をすると、近くの LX-D02 を自動で探して接続し、
見つけたアドレスを設定ファイル（`lily_print_config.json`、アプリと同じフォルダ）へ保存する。
次回からは保存したアドレスで直接つなぐ。別の個体に替えるときは欄を消して探し直すか、手で書き換える。

## 仕様メモ

- 画像は横 384px にリサイズしてから送る（384px ちょうどの画像は等倍）。
- プレビュー生成は `lxd02.protocol.rasterize` と同じ変換で、印刷ドットと完全一致することを検証済み。
- 日本語テキストは扱わない（lxd02 のテキスト描画は同梱 DejaVu フォントで日本語が豆腐になるため）。
  テキストは FontMemo 等で画像化して、このアプリで刷る。

## exe 化（任意）

`build_exe.bat` を実行すると `dist\LilyPrint.exe` ができる。設定ファイルは exe と同じフォルダに作られる。

## トラブル時

- 「プリンタが見つかりません」：電源・スマホ BT の OFF・USB 給電を確認。数分放置で自動電源オフになる。
- 保存したアドレスで見つからない場合は、欄を消して「探す」で探し直す。
